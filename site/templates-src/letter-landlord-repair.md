# Template — Landlord: Written Repair Request

> Fill every `{{slot}}`; send in writing (email or the portal), and log it in `00-log.md`.
> Keep tone firm and calm. This is rung 1 of Chapter 2 — a follow-up notice is rung 2.

```
Date:           {{DAY-MONTH-YEAR}}
To:             {{PROPERTY MANAGER / LANDLORD NAME}}
From:           {{YOUR NAME}}, unit {{UNIT #}}, {{BUILDING ADDRESS}}
Subject:        Repair request — {{ISSUE IN FOUR WORDS}} — unit {{UNIT #}}

Dear {{NAME}},

I'm writing to ask for a repair in unit {{UNIT #}}: {{THE PROBLEM, IN ONE PLAIN SENTENCE — "the boiler is not producing hot water."}}

Facts:
1. I first noticed the problem on {{DATE YOU FIRST SAW IT}}. See attached photos 1–3.
2. I raised it verbally with {{WHO YOU TOLD, IF ANYONE}} on {{DATE}}.
3. Nothing has changed as of today, {{DAY-MONTH-YEAR}}, and this affects {{WHAT'S AFFECTED: hot water / heating / a working door / a habitable room}}.

REMEDY REQUEST: Please arrange for the repair within {{REASONABLE-WINDOW — 7 DAYS FOR MOST / 48 HOURS IF SAFETY-RELATED}}, and let me know when a technician is coming.

Photos (attached as 1–{{N}}) show the problem. If any engineer visit needs help getting in, I'm flexible {{WHEN YOU'RE FREE}}.

You can reach me at {{PHONE-OR-EMAIL}}. I'm not making a complaint — I'm sure this has just slipped through the net, and I'm sure it'll get sorted quickly.

Thank you — I appreciate a repair you can book soon, and let me know if you'd like any more photos.

{{YOUR NAME}}
```
