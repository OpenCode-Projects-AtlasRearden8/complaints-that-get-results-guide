Letter Templates

Editable right in this page, plus raw files in site/templates-src/. Fill every slot, delete what doesn't apply, then run the Chapter 6 redaction + tone review. Keep each letter to one page.

How to use one

  1. Pick the letter that matches your Chapter 2 escalation rung.
  2. Edit it below (or open the raw .md file), then save a copy in your dispute folder's 04-letters-sent/ folder.
  3. Redact personal details first, then run the AI tone review from Chapter 6.
  4. Send it, log it in 00-log.md, and set the two calendar reminders from Chapter 4.
